# KURONEX GAMES

> **Build Your Own Library.**

KURONEX GAMES is a next-generation gaming platform built around your personal game library. Discover games based on your taste, mood, and the way you play.

## Brand Identity

- **Brand Name:** KURONEX GAMES
- **Short Name:** KURONEX
- **Tagline:** Build Your Own Library.
- **Theme:** Dark Void (`#020405`) with Signature Accent (`#FF263D`) and Electric Cyan highlights.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Architecture

- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
- **Styling:** Vanilla CSS design system tokens + Tailwind CSS v4
- **3D & Shaders:** Three.js, React Three Fiber, React Three Drei, Canvas GL shaders
- **Motion:** Framer Motion
- **Authentication:** Custom cryptographically secure session-based authentication with `scrypt` hashing
